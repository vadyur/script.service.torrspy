# TorrSpy Service | Сервис TorrSpy

[![Kodi Addon](https://img.shields.io/badge/Kodi-Addon-blue.svg)](https://github.com/vadyur/script.service.torrspy)

## English

**TorrSpy Service** automatically detects video streams launched via **TorrServer** and syncs metadata for movies and TV shows directly into your **Kodi Media Library**. If a video playback is interrupted, the plugin offers to save the content to your library while preserving all metadata and your exact playback position. This is especially convenient for TV shows.

### 🚀 Key Features
* **Automated Library Management**: Automatically add unwatched movies and TV shows to your Kodi library.
* **Smart Metadata Sync**: Automatically detects and fetches metadata for content played via TorrServer.
* **Position Tracking**: Offers to save playback position and metadata when a stream is interrupted.
* **TorrServer Integration**: Seamlessly works with TorrServer to stream torrents directly in Kodi.
* **Advanced Automation**: Options to add all torrents from your TorrServer database to the library.
* **Android TV Support**: Easy tools to create playlists for Android TV channels.

### 🛠 Installation
1. Ensure you have **TorrServer** running.
2. Install the **TorrSpy Service** addon via the [Kodi repository](https://github.com/vadyur/script.service.torrspy).
3. Configure your TorrServer host and port in the addon settings.
4. (Optional) Install `plugin.video.torrserve-next` for an enhanced experience.

## Русский

**TorrSpy Service** автоматически распознает видеопотоки, запущенные через **TorrServer**, и синхронизирует метаданные фильмов и сериалов прямо в вашу **медиатеку Kodi**. Если просмотр был прерван, плагин предложит сохранить видео в медиатеку, полностью сохранив данные о контенте и позицию просмотра. Это особенно удобно для сериалов.

### 🚀 Основные возможности
* **Автоматизация медиатеки**: Автоматическое добавление недосмотренных фильмов и сериалов в медиатеку Kodi.
* **Умная синхронизация метаданных**: Автоматическое определение и получение метаданных для контента, запущенного через TorrServer.
* **Сохранение позиции**: Предложение сохранить позицию просмотра и метаданные при прерывании потока.
* **Интеграция с TorrServer**: Бесшовная работа с TorrServer для стриминга торрентов прямо в Kodi.
* **Расширенная автоматизация**: Возможность добавления всех раздач из базы TorrServer в медиатеку.
* **Поддержка Android TV**: Удобные инструменты для создания плейлистов для каналов Android TV.

### 🛠 Установка
1. Убедитесь, что у вас запущен **TorrServer**.
2. Установите аддон **TorrSpy Service** через [репозиторий Kodi](https://vd-plugins.info/repo/repository.vd-2.0.0.zip).
3. Настройте хост и порт TorrServer в настройках аддона.
4. (Опционально) Установите `plugin.video.torrserve-next` для еще более удобной работы.
